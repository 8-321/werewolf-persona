# 狼人杀人格图鉴

36 道核心题，难分胜负时最多加 6 道校准题，约 4 分钟测出你在牌桌上的身份人格：悍跳狼、倒钩狼、深水狼、预言家、守卫、整活玩家……没玩过狼人杀也能测。

**在线测评**：https://8-321.github.io/werewolf-persona/

![封面](screenshots/01-cover.jpg)

## 特点

- 12 种身份人格，结果页含频道读数、关系图谱、分享卡
- 36 + 6 题自适应校准，答题进度本地保存，可中断续答
- 纯静态（HTML/CSS/JS），零依赖、零后端
- 已跑 40/40 端到端用例，效果图在 `效果图/`

## 本地运行

```bash
python -m http.server 8080
```

## 结构

```
index.html   页面骨架
style.css    视觉与动效
app.js       答题流程 / 计分 / 结果渲染
data.js      题库、身份人格、文案
og.png       分享图
效果图/       E2E 截图与报告
```
